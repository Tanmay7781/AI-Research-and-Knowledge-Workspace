# AI Research & Knowledge Workspace

An AI-powered document intelligence platform built using:

- React
- Express.js
- PostgreSQL
- FastAPI
- ChromaDB
- Gemini API

## Project Structure

frontend/   - React application

backend/    - Express.js API

ai-service/ - FastAPI + RAG + AI

## Planned Features

- Authentication
- Document Upload
- AI Chat with Documents
- Semantic Search
- Flashcards
- Quiz Generation
- Study Planner
- Citation Generator
